# 85 · 流派与道心

> **一句话**：原来的十五本功法只差数值大小，选哪本只是选大小；
> 加上**流派**之后，选哪本变成**走哪条路**。

---

## 一、为什么要加这一层

R9 之前，功法系统是这样的：

```
道途（5）× 品阶（3）= 15 本
```

道途决定「强化哪个方向」，品阶决定「强多少」。这套结构清楚，但**没有玩法身份**——
地阶御守和玄阶御守的区别只是 +130% 和 +60%，玩家永远选数值大的那本。

R10 加了一层**正交的流派**：

```
道途（强化什么）× 品阶（强多少）× 流派（走哪条路）
```

**流派是正交的**，所以同一个道途下可以有不同流派的选择，这才构成取舍。

---

## 二、核心规则：只有主修位的流派生效

这是整个系统的**唯一一条硬规则**，也是最需要守住的一条：

> **主修位吃满数值 + 流派机制；辅修位只吃 45% 的数值，不给机制。**

为什么这样设计：

- 如果两个位置都能带流派，玩家会堆叠最强的两个机制，取舍消失
- 「一个人只能走一条路」符合修仙设定，也让「换主修」变成一个**重大决定**
- 换主修不需要任何惩罚机制——光是丢掉原来的机制本身就够痛了

---

## 三、道心（道德值）

### 它不是善恶评分

代码里叫 `morality`，界面上叫**道心**。它记录的不是「你做过什么坏事」，
而是**你在这个地界上被当成什么人**。这个区别很重要：

- 它**不阻止**你炼人丹，只是让你**变成**另一个人
- 它不给你「善恶」标签，只给你**后果**

### 五个档位

| 档位 | 范围 | 洞天生还 | 攻伐胜算 | 领地赋税 |
|---|---|---|---|---|
| 魔道 | 0–19 | **−25pp** | **+10pp** | ×0.70 |
| 旁门 | 20–39 | −10pp | +5pp | ×0.85 |
| 中庸 | 40–60 | 0 | 0 | ×1.00 |
| 正道 | 61–80 | +5pp | −3pp | ×1.15 |
| 道心通明 | 81–100 | +10pp | −6pp | ×1.30 |

**三条后果构成一组真正的取舍：魔道能打但养不起地，正道养得起但打不动。**

- 洞天惩罚是**叙事性的**：血债缠身的人走洞天，天不佑他（对应你提的「道德值低会更容易在洞天中死亡」）
- 攻伐加成是**威慑**：凶名在外，守方未战先怯
- 赋税倍率是**民心**：抢来的地，人不肯交粮

### 怎么变

| 来源 | 变化 |
|---|---|
| 主修血煞一脉 | **每秒 −0.010**，持续下坠，不设底 |
| 主修其它流派 | **回归中道 50**，离得越远回得越快（每秒最多 ±0.004） |
| 炼一枚人丹 | **−8** |
| 施粥赈济 | **+6**（花 6 万银两） |

### ⚠️ 一个踩过的坑：不能让它无限爬升

最初的实现是「不走邪路就持续 +0.004/s 回升」。测试立刻抓到了问题——
**跑够时间道心就顶到 100，白拿「道心通明」的 +30% 赋税**，
正道档位变成免费加成，魔道也就失去了存在意义。

改成**回归中道**之后：

- 想守住正道**必须持续施粥**（每小时约 25 万银两的维护成本）
- 想堕落只需要换一本功法（零成本）
- **堕落容易，回头难** —— 这才是这套机制该有的手感

**道心不跨周目保留** —— 轮回是重新做人，前世的血债不该跟着走。

## 四、六个流派

| 流派 | 独有机制 | 代价 |
|---|---|---|
| **玄门正宗** | 无（基准） | 无 |
| **血煞魔功** | 解锁**炼人丹**、战力 +35% | 修炼 −10%、凡人死亡率 **×1.25**、道心持续下坠 |
| **合欢双修** | 凡人出生率 **×1.40**、修炼 +35% | 战力 −25%、道心略降 |
| **剑修** | 战力 +55%、攻伐胜算 +6pp | 修炼 −18%、洞天生还 −6pp |
| **丹修** | 炼丹成功率 +12pp、修炼 +20% | 战力 −20% |
| **器修** | 炼器成功率 +12pp、战力 +15% | 修炼 −15% |

### 血煞魔功：人丹

```
炼一枚：献祭凡人 5 口 + 2 灵石 → 人丹 ×1，道心 −8
服下一：该修士修为 +35%（当前一层所需）
```

**原料是人。** 凡人人口是家族银两的来源，道心是洞天里的保命符，
所以「用命换修为」在这里是字面意思——这是全篇最重的代价。

它同时触发了三条后果链：

```
炼人丹 → 凡人变少 → 银两变少 → 科技/建筑变慢
      ↘ 道心下降 → 洞天更危险 → 修士更容易死
      ↘ 凡人死亡率 ×1.25 → 人更少（雪球）
```

### 合欢双修：人丁

唯一能**放大凡人出生率**的流派。在凡人篇它是最强的经济流派，
但一进仙途就发现战力跟不上——**同阶的合欢修士往往是最先倒下的那个**。

## 五、九本新功法（共 24 本）

| 流派 | 功法 |
|---|---|
| 血煞 | 血煞炼形诀（黄/御守）、万魂幡（玄/御守）、人丹要术（地/炼气） |
| 合欢 | 合欢采补术（黄/炼气）、欢喜禅功（玄/炼气） |
| 剑修 | 青莲剑歌（玄/御守）、斩妄剑经（地/御守） |
| 丹修 | 丹鼎真解（玄/炼气） |
| 器修 | 神工录（玄/御守） |

**数值上普遍比同阶的玄门功法略高一点**——代价写在流派上，不写在数值里。
这是刻意的：如果流派功法的数值还更低，那就没人会去试。

前十五本**不带 `school` 字段**，一律按玄门正宗处理（`schoolOf()` 的默认值），
所以**旧存档不需要任何迁移**。

## 六、百科

每个功法**单独一条**（不再是按道途归并），这是你明确要求的：

```
manual-<id>   24 条  品阶 / 道途 / 流派 / 本功效果 / 灵根要求 / 流派机制 / 流派代价
school-<id>    6 条  一句话 / 独有机制 / 代价 / 本流派收录了几本
morality-*     4 条  道心是什么 / 五个档位 / 怎么变 / 人丹
```

功法条的**解锁条件是「收录了这本」**，所以百科本身就是收集进度的镜子。

## 八、已知待办

1. **数值未经试玩验证。** 道心下坠 −0.010/s 意味着从 50 掉到魔道约 52 分钟——
   这个节奏是算出来的，不是玩出来的。如果太慢/太快，改 `MORALITY_DRIFT_EVIL` 一个数即可。
2. **施粥的成本可能偏高。** 6 万银两/次，守住正道约合每小时 25 万——中期可能吃不消。
3. **流派之间还没有互斥关系。** 目前可以「主修血煞 + 辅修剑修拿数值」，
   虽然机制不叠加，但数值上仍然吃到了。是否要加互斥，等试玩反馈。
4. **人丹目前只能加修为。** 可以考虑加一种「人丹炼器」的路子（血煞 + 器修联动）。
5. **道心还没有和宗门、坊市挂钩。** 比如「魔道家族进不了正道宗门」是很自然的延伸。
