# 《修仙世家》整体策划案

> 版本：v1（Round 1）
> 覆盖范围：从**凡人**到**化神**的完整周目循环，以及炼丹／炼器／炼符／灵根／地图／功法／轮回金手指／内置百科八大区块。
> 本文是**总纲**。每个区块的细化设计各有一份独立文档，落地时以那些文档为准。
> 当前可玩产物：`game.html`（单文件，凡人篇 + 炼气篇前半）。本轮起改为**分区块源码 + 构建**。

## 一、定位与核心循环

### 1.1 这是什么

一个**挂机 + 间隔重复背单词**的修仙家族经营游戏。玩家扮演一个家族的家主，
从一块田地、十口人开始，把家族一步步推上仙途。

三层节奏叠在一起：

| 层 | 周期 | 玩家在做什么 | 现有实现 |
|---|---|---|---|
| **挂机层** | 秒～分钟 | 看数字涨，点几下营造／派遣 | ✅ 凡人篇 |
| **决策层** | 十分钟～小时 | 分配资源、选功法、挑路线 | ✅ 炼气篇（部分） |
| **周目层** | 数十小时 | 冲境界、轮回、点金手指 | ❌ 待建 |

### 1.2 核心循环（一周目）

```
凡人：人口 ──> 银两 ──> 营造/科技 ──> 商路 ──> 秘闻 ──> 灵石
                                │
                                ▼
炼气：祛障丹 ──> 修士 ──> 职责 ──> 修为 ──> 炼气九层
                                │
                                ▼
筑基起：突破瓶颈 ←── 丹药（炼丹）
         │         ←── 法器（炼器）
         │         ←── 符箓（炼符）
         │         ←── 灵根（决定上限与速度）
         │         ←── 材料（地图探索 / 征伐）
         ▼
化神：周目终点 ──> 轮回 ──> 传承点 ──> 解锁金手指 ──> 下一周目
```

**每一层都必须给下一层供货，且不能自己闭环。** 这是整个设计的骨架：
炼丹要材料，材料要地图，地图要战力，战力要境界，境界要丹药——玩家永远缺一样。

### 1.3 三条贯穿始终的设计原则

1. **每个系统都要有「负面对价」。**
   已有先例：演武台与驿站抬高死亡率、探秘者砍商路收益、宗门安全但吃不到家族功法。
   新增系统必须同样有代价，否则会退化成「能建就建」。
2. **数字要能被玩家算出来。**
   所有概率、倍率、代价都写在界面上（当前已有的：洞天生还率预估、突破成功率、净赚）。
   不做隐藏公式。
3. **每个区块自带注释与调参入口。**
   数值集中在 `data/*.js` 的表里，规则集中在 `systems/*.js`，
   改数值不需要读逻辑，改逻辑不需要翻界面。

## 二、境界体系：炼气 → 化神

### 2.1 境界表

凡人篇之后的完整阶梯。**大境界 5 个，小境界共 19 级。**

| 大境界 | 小境界 | 修为上限倍率 | 突破所需 | 寿命压力 | 地图开放 |
|---|---|---|---|---|---|
| **炼气** | 一层～九层 | ×1 | 无（自动晋升） | — | 无 |
| **筑基** | 初期／中期／后期／圆满 | ×4 | 筑基丹 + 灵石 | — | 一阶区域 |
| **金丹** | 初期／中期／后期／圆满 | ×16 | 金丹 + 三味真火 | 寿元 −10% 人口 | 二阶区域 |
| **元婴** | 初期／中期／后期／圆满 | ×64 | 元婴丹 + 婴变符 | 需驻守领地 | 三阶区域 |
| **化神** | 初期／中期／后期／圆满 | ×256 | 化神丹 + 天地灵物 | 周目终点 | 四阶区域 |

设计要点：

- **炼气期不设突破概率**（现有的确定性晋升保留），作为新手区。
  从筑基开始才引入「瓶颈」——一次失败要有代价，玩家才会去准备丹药与符箓。
- **每一个大境界都要一个新的材料来源**：
  筑基丹要灵药（地图一阶）、金丹要矿石与地火（二阶）、元婴要符纸与魂材（三阶）。
  这样炼丹／炼器／炼符三个区块会**依次**被解锁，而不是一次性砸给玩家。
- **寿元压力**是金丹期之后的新负面对价：境界越高、家族要供养的凡人越多，
  逼玩家在「扩张」与「精修」之间取舍。

### 2.2 修为与突破

```
修为增长 = 基础速率 × 灵根系数 × 功法倍率 × 职责倍率 × 洞府加成
突破成功率 = 基础率 + 丹药加成 + 符箓加成 + 灵根修正 − 越级惩罚
失败后果  = 修为倒退 N% ＋ 丹药作废（法器可减免）
```

- 现有 `RETREAT_XP_PER_SECOND = 0.0012`、`cultivateXpNeeded(level) = 45 × L²` 保留为炼气期公式。
- 筑基以上改用「层内修为 + 瓶颈」两段式：修为满了停在瓶颈，需要主动点「突破」。
- **突破是玩家主动触发的**，不是自动的——这是把决策权交还给玩家的关键。
  现有炼气期的 `while(xp >= need) realm++` 自动跳级保留为炼气期专属。

### 2.3 与现有代码的接合

现有 `person.realm` 是 1–9 的整数，`cultivateLevelCap` 按出身给 6 或 9。
新体系需要把它升级成**全局境界序号**：

```js
// 0=凡人 1..9=炼气一~九层 10..13=筑基初期~圆满 14..17=金丹 18..21=元婴 22..25=化神
person.realmIndex = 1;
```

**存档兼容**：读档时把旧的 `realm: 1..9` 直接映射为 `realmIndex: 1..9`，语义不变。
`origin`（innate/awakened）改为只影响**灵根**，不再影响上限——上限由境界体系统一决定。

## 四、各区块设计要点

> 以下是**要点**，不是完整设计。每个区块动工前各写一份细化文档。

### 4.1 灵根（P0）

**作用**：决定修炼速度上限、能修习的功法类型、突破成功率修正。**是周目重置后最有价值的重开资源**。

| 灵根 | 权重 | 修炼速度 | 突破修正 | 可修功法 |
|---|---|---|---|---|
| 天灵根（单系） | 0.5% | ×2.0 | +15% | 全部 |
| 双灵根 | 4% | ×1.5 | +8% | 两系 |
| 三灵根 | 15% | ×1.15 | +2% | 两系 |
| 四灵根 | 30% | ×1.0 | 0 | 一系 |
| 五灵根（伪灵根） | 50% | ×0.7 | −8% | 一系 |

- **五系**：金木水火土。灵根系别决定哪些功法能修（现有功法的「道途」要扩成「道途 × 系别」）。
- **测灵根**是一个仪式：开局或第一次踏入炼气时随机，也可以用道具重测（消耗灵石，有下限保护）。
- **负面对价**：好灵根的天才**更难留住**——天赋越高，越容易被宗门挖走（宗门招募概率随天赋上升），
  玩家要在「放他去宗门换资源」和「留在族里慢慢养」之间选。

### 4.2 境界与突破（P0）

- 见 §二。核心是**把自动晋升改成主动突破**，并给每个大境界配一个材料门槛。
- **瓶颈期**要有独立的 UI 状态：修为满了会停在「圆满」，面板提示缺什么材料。
- 突破有**公开的成功率与失败代价**（当前洞天生还率已经这么做了，保持一致）。

### 4.3 地图与征伐（P0）

把现有的「洞天 4 处 + 势力 3 个」升级成**有位置关系的地图**。

```
        [青苔谷]──[流霞坡]──[玄阴涧]──[太虚原]
            │         │          │
        [青木寨]  [黑水门]   [玄铁宗]   [?]
```

- **节点类型**：资源点（灵药／矿石／符纸）、洞天（机缘／功法）、势力（征伐／领地）、秘境（限时）。
- **相邻才能去**：出门要按距离消耗「行程」或时间，让「去哪儿」变成真决策。
- **战力指导**：每个节点直接标注「建议境界」与「胜算%」，不再让玩家盲猜。
  这是「对出门征伐提供更形象的指导」的落点。
- **领地占领后产出**：修掉现有「攻伐零成本、占领无收益」的漏洞——
  占领后每 tick 产出材料，但需要**驻守修士**（占掉一个战力位），且会被反攻。

### 4.4 炼丹（P1）

```
灵药（地图采集） + 丹方（秘闻/坊市/势力掉落） + 火种（炼器产物） ──> 丹药
```

- **丹方**是一条独立的收集线（像现在的秘闻），每张丹方写明：材料、火候、成丹率、品阶。
- **火候**是个小交互：投入灵石控制火温，温度曲线对得上才出高品质丹（而不是纯随机）。
  这样「炼丹」本身有操作感，不是又一个挂机按钮。
- **熟练度**：同一张丹方炼得越多越稳（失败率下降），**上限与灵根挂钩**。
- **负面对价**：炼丹消耗**凡人人口**作为药童（低阶时），或消耗**修士寿元**（高阶时）。
- 产出：突破丹（境界）、增益丹（临时倍率）、疗伤丹（战后恢复）、**废丹**（可回炉）。

### 4.5 炼器（P1）

```
矿石（地图开采） + 图纸 + 地火（需占领含地火的领地） ──> 法器
```

- **法器有耐久**：出征会磨损，需要修复（消耗材料）。
  这让瓷器不是「造一次用一辈子」，给炼器一个持续需求。
- **法器分位**：攻击（提高征伐胜率）／防御（降低战败损失）／辅助（提高突破率）。
  与现有的「御守」功法配合，形成装备 + 功法的双层配置。
- **负面对价**：地火要占一块领地，而领地要驻守修士——占用的战力是从别处挪来的。

### 4.6 炼符（P1）

```
符纸（特定区域产出） + 符墨 + 灵纹（需悟性） ──> 符箓
```

- **符箓是一次性消耗品**，与法器（可修复）形成互补：
  法器是重投资低消耗，符箓是轻投资高消耗。给不同阶段的玩家两条路。
- **灵纹**是个轻解谜：一组节点用最少的笔画连起来，画对了符箓品质更高。
  可以复用治学区块的思路（低门槛、可跳过、不影响主线）。
- 产出：突破符（提高突破率）、传讯符（远程指挥，减少行程）、护身符（免一次死亡）。

### 4.7 功法（已完成，待扩展）

现有的「道途 × 品阶 + 主修/辅修 + 参悟」保留。需要扩展：

- 道途从 5 条扩到 **5 道途 × 5 系别**的组合（灵根决定能修哪些）。
- **宗门功法**是独立目录：入宗门的修士能学到家族拿不到的功法，
  但**宗门功法不能传给家族**（现有文案已经这么写了，把它做成真机制）。

### 4.8 周目与金手指（P2）

**轮回条件**：任一修士踏入化神，或家族总战力达到阈值。

```
轮回 ──> 结算「传承点」 ──> 在「轮回殿」消费
                              ├─ 解锁金手指（一次性，永久生效）
                              ├─ 保留部分资产（灵石/功法/灵根）
                              └─ 提升开局起点
```

**传承点**按本周目达成的里程碑累加（境界、占领领地数、功法收藏、丹方收藏……）。

**金手指**是修仙小说的经典梗，做成可解锁的「开局附加规则」。
每个金手指都要**同时有好处和代价**，否则就成了控制台作弊：

| 金手指 | 出处梗 | 效果 | 代价 |
|---|---|---|---|
| **掌天瓶**（小绿瓶） | 韩立 | 灵药生长速度 ×10，可催熟 | 只对灵药有效；持有者每次闭关寿命 −1% |
| 神秘小瓶 | 通用 | 每日可凝一滴灵液，直接换灵石 | 数量固定，不随境界增长 |
| 戒指里的老爷爷 | 斗破 | 开局多一位「隐世长老」指点 | 他会在你化神前索取一半修为 |
| 重生记忆 | 通用 | 保留上一周目的科技与部分功法 | 灵根随机，不能测 |
| 天生道体 | 通用 | 灵根必定 ≥ 三灵根 | 族人死亡率 +20%（天妒） |
| 系统面板 | 通用 | 所有概率可见（默认只有区间） | 每次突破额外消耗灵石 |

**设计重点**：金手指是**规则改变**，不是数值 +N。玩家第二周目的体验应该和第一周目不同，
而不是「同样的游戏，数字大一点」。

### 4.9 百科（P1）

**单开一个栏目**，是「不玩也能看」的那一层。词条分三类：

| 类型 | 内容 | 解锁方式 |
|---|---|---|
| **系统词条** | 演武台＝对外扩张，会死人；商队驿站同理 | 建筑/科技解锁时自动开放 |
| **境界词条** | 炼气、筑基……各自意味着什么，寿命、战力、社会地位 | 踏入该境界时开放 |
| **世界观词条** | 地理、势力、宗门、灵药图鉴、典故 | 探索到该地/采集到该物时开放 |

**写法要求**：百科条目不是说明书，是**志书**。
例如「演武台」条目应该写成：

> **演武台**
> 族中子弟习武较技之所。立台者，乡里不敢轻慢，田产地价随之而落。
> 然武事既兴，子弟多走出去争地，**回不来的人也多了**。
> *（效果：每座地产价格 −4.6%（递减）；死亡率 +0.06%/秒）*

上面的正文负责代入感，引文里的效果数据负责可查。**两者都要有。**

百科同时承担**新手指引**：当前的天赋、职责、突破等系统说明散落在各处 tooltip 里，
统一收进百科，tooltip 只留一句短提示。

### R9 的实际结果

目标说「发展到一定境界通过重开应该给下一个周目提供增益，可以单开一个栏目，
里面可以解锁一些比较经典的金手指，比如韩立的小绿瓶等」——做成了**第七个页签「轮回」**。

**核心原则：金手指改变的是规则，不是数值。**
「灵石 +50%」是数值膨胀，第二周目就只是数字大一点；**掌天瓶**则是
一个第一周目里不存在的做法——别人的药材产量是固定的，你的可以涨。

| 金手指 | 规则改动 | 代价 |
|---|---|---|
| **掌天瓶** | 药材/矿料/符文产出 **×2.5** | 全族修炼 **−10%** |
| **戒中老者** | 冲关成功率 **+12 个百分点** | 冲关成功额外耗**一枚同阶丹药** |
| **前世记忆** | 开局解锁 3 项科技 + 已知 2 处地点 | 答题增益**减半** |
| **气运加身** | 洞天生还率 **+15 个百分点** | 灵石产出 **−20%** |

**「每件都必须有代价」是硬约定**，测试里有一条专门盯它。而且代价都咬在别的体系上，
所以带了金手指之后最优策略会**真的改变**。

- **轮回门槛 = 化神初期**（不是圆满）：圆满要跑满 44 小时，让人在 26 小时左右
  就能选择重开，比逼他跑完更尊重时间。
- **解锁与携带分离**：解锁花轮回点（永久），携带从已解锁里挑（最多 2 件，免费）。
  分开之后轮回点是投资、携带位是取舍——这个取舍才是周目的玩法。
- **重置保留名单**里最关键的一条：**答题记录跨周目保留**。
  这个游戏的答题是真实的六级词汇学习，重开清空错题本等于毁掉它最有实际价值的部分。
- 顺带修掉一个真 bug：`createState()` 只给骨架，丹房/器坊/符房是惰性初始化的，
  重置后必须补一次 `repairCultivation()`，否则新周目头几帧读到 `undefined`。

### R8 的实际结果

目标是「增加游戏内置的百科，单开一个栏目」——所以做成了**顶栏第六个页签**。

**两层结构**，正好对应目标里举的两个例子：

| 层 | 作用 | 例（演武台） |
|---|---|---|
| **志书** | 代入感 | 「走出去争地的子弟，回不来的人也多了」 |
| **数据引文** | 可查 | 「地产折扣递减（趋近 −60%），死亡率 +0.06%/秒」 |

**最重要的决定是「聚合，不重抄」**：前七个区块早就把背景文字写在数据表自己身上了
（建筑的 `lore`、地图的 `lore`、丹方/法器/符箓/境界的 `desc`），
所以九章 63 条里**只有两章是新写的正文**（境界 6 条、规矩 11 条），
其余全部直接引用。冒烟测试里有一整节专门当这条约定的守门人——
拿原表文字去比对百科正文，**改表不改百科就会挂**。

- **数据引文必须是函数**：地图条目的引文里有四个产量数字，分别来自 R4/R5/R6/R7。
  写成静态字符串，以后调产量百科就会撒谎。
- **搜索覆盖正文而不只是标题**：玩家记得「死亡率」三个字就能找到演武台。
- **只搜已解锁的条目**，不然是剧透。

### R2 的实际结果（供后续参照）

- 境界扩到 **5 大境界 / 25 级**（凡人 → 化神圆满），`realmIndex` 取代了旧的 `realm`。
- **小境界自动晋升，跨大境界必须主动冲关**；门槛、成功率、失败惩罚都在 `REALM_GATES` 里。
- **节奏从 572 小时压到 44.6 小时**：`REALM_XP_RATE` 由 0.0012 改为 1.0，
  修为曲线（`xpBase × 层号²`）本身没变。逐档：炼气 3.56h / 筑基 4h / 金丹 7h / 元婴 12h / 化神 18h。

### R3 的实际结果

- **五行 + 五档灵根**（天/双/三/四/五），后天的好档合计只有 4.5%，天生有 14%。
- **灵根是三件事的决定者**：修炼速度（×2.0 ~ ×0.7）、突破修正（+15% ~ −8%）、
  **境界硬上限**（化神圆满 ~ 元婴圆满）。
- **功法改成「家族装备、个人按灵根取用」**：同一套功法，灵根不合的族人才一点都吃不到。
  这让「族人灵根够杂」变成一种资产。天灵根对本系功法另有 ×1.5 专精。
- **负面对价**：宗门只收三灵根以上，并按资质出**引荐礼**（灵石）。
  灵石是突破门槛的硬通货，「换钱还是留人」是真选择。
- **测灵根**：花灵石重测，**保证不亏**（更差就保留原有的），是灵石的稳定去处。

### R4 的实际结果

- **洞天 4 处 + 势力 3 个** 两张平表 → **4×2 网格地图，8 个节点**，相邻才能去。
  邻接关系由 col/row 推出，不单独维护邻接表。
- **每个节点直写建议境界、预估生还率、胜算百分比、镇守需求**——
  这就是「对出门征伐提供更形象的指导」的落点。
- **修掉了攻伐的零成本漏洞**：原来占领没有任何收益，最优解是无脑连点。
  现在**占领后要派人镇守才有赋税**，镇守不足会积累民怨直至叛离（确定性计时，不是随机事件）。
- 四个势力节点全部镇住需要 7,535 战力，而一名炼气九层只有 549 ——
  **战力从此是双重资源**：既决定打不打得过，也决定守不守得住。
- 灵石多了一条靠扩张获得的来源（满打满算约 3,400 灵石／周目），定位是矿场之外的第二条腿。

### R5 的实际结果

这一轮把前三个区块留下的接口一次填上：

| 留下的空洞 | 怎么填的 |
|---|---|
| R2：`REALM_GATES` 的「暂定」灵石数 | 四道门槛改成 **丹药为主 + 少量灵石**（8/30/120/300），缺丹直接拒绝并点名缺哪一味 |
| R3：白占位置的「木」属性 | **木灵根 = 炼丹加成**（+12% ~ +24%），丹道属木 |
| R4：节点产出统一是灵石 | 四个势力节点**各产一种药材**，规则与赋税一致（已占领 + 有效镇守） |

- **药材来自地图**，所以「想炼丹就得先打通商路，打通了还得守得住」——
  R4 的镇守压力在 R5 有了第二重回报。
- **六个丹方**，成功率 90% → 20% 单调下降；**失败损失全部材料**。
- **丹炉五级**（+0% ~ +25%）与**熟练度**（每方独立，0~10）是两个明文可见的投资方向，
  所以正确的玩法是「先投资再炼」，而不是硬砸材料。
- 丹炉升级**同时消耗灵石与银两**，让凡尘篇的银两经济在化神期仍然有用。

### R6 的实际结果

**炼器刻意做成与炼丹同构**——两条线共享同一套形状，加第三个体系（炼符）时
不需要重新发明约定：

| 环节 | 炼丹 | 炼器 |
|---|---|---|
| 材料 | 药材，来自已占领且有效镇守的节点 | 矿料，**同一批节点** |
| 主事人 | 丹师（木灵根加成） | 器师（金灵根加成） |
| 设施 | 丹炉五级 | 锻造台五级 |
| 成品 | 突破门槛的消耗品 | **装备，直接加战力** |

- **矿料与药材同源但独立**，所以玩家不必在两条线之间做排他选择；
  真正的瓶颈是领地与镇守战力。
- **九个法器**（三部位 × 三品阶），每个部位只能装备一件。
  部位有性格：兵器战力最高损耗最大；护甲在攻伐里掉得快；**法宝是唯一给洞天生还率的**，
  且在洞天里掉得最快。
- **负面对价是耐久**：法器是资产，资产要养。耐久越低效果越弱（从七成起跳），
  归零则完全失效，需花矿料重祭。这让矿料在中后期仍然有价值。
- **五行在 R5/R6 各有了归宿**：木→炼丹、金→炼器、水火土→功法道途。

### R7 的实际结果

**炼符不是「第三个一样的系统」，而是补上了第三种时间尺度：**

| 体系 | 成品性质 | 负面对价 | 归属 |
|---|---|---|---|
| 炼丹（R5） | 一次性消耗品，进突破门槛 | 失败损失全部材料 | 木 |
| 炼器（R6） | 长期资产，加战力 | **耐久**（资产要养） | 金 |
| **炼符（R7）** | **「下一次行动」的加成** | **保质期 3 小时**（囤不住） | 火 |

- **四张符分别接在四个已有的决策点上**（冲关成功率 / 洞天生还率 / 攻伐胜算 / 全族修炼），
  没有新建任何一套机制，只是往已有的判断里各加了一项可消耗的加成。
- **「下一次」的语义**：挂上之后等对应行动消费，**无论成败都用掉**。
  如果失败能保留，玩家就会「先用一张试试运气」，符就退化成免费重试。
- **保质期且「补货不延长」**：如果补货能刷新期限，玩家隔两小时补一张就能永远保下来，
  保质期形同虚设。现在的规则让**存货量**与**新鲜度**成为一对真实的矛盾。
- 至此五行全部有归宿：木→炼丹、金→炼器、**火→炼符**、水土→功法道途。

`docs/32-炼符.md` 里还留了一张**三体系对照表**——要加第四条线（比如阵法）照抄一列即可。

1. `scripts/smoke.mjs` 全绿（含新增区块的断言）；
