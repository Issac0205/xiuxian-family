# 秘籍（功法）机制 · 策划案

> 目标版本：`game.html`（炼气篇完整扩展试玩版）
> 撰写依据：该文件现有的 `CULTIVATION_MANUALS` / `OBTAINABLE_MANUSALS` / `grantManual` /
> `manualTrainingMultiplier` / 洞天 / 攻伐 / 修士职责五套已有系统。

---

## 一、现状盘点：机制已经接通，但没有「决策」

炼气篇里功法这条线其实**已经跑通了**，只是内容极薄。逐项核对：

| 组件 | 位置 | 现状 |
|---|---|---|
| 功法目录 | `CULTIVATION_MANUALS` / `OBTAINABLE_MANUALS` | 3 本，字段只有 `trainingMultiplier`（1.4 / 2.1 / 3.2） |
| 获取途径 | 洞天 4 处、攻伐 3 处 | `manual` 概率 5%/15%/34%/70%、10%/32%/70% |
| 获得处理 | `grantManual(state, grade)` | 加进 `manuals`，并**自动装备更强的那本** |
| 生效处 | `manualTrainingMultiplier(state)` | 只乘在 `retreat` / `sect` 的修为增长上 |
| 切换 | `immortalAction('equip')` | 能手动换 |
| 存档 | `save.js` | `manuals` / `equippedManual` 都做了校验与兜底 |
| 面板 | `功法阁`（`data-panel="cultivation-manuals"`） | **只有一个空状态文案**，没有列表 |

### 问题：这套东西没有产生任何选择

1. **三本功法只差一个数字。** 都是「修炼速度 ×N」，高品阶全面碾压低品阶——
   拿到《周天星河诀》之后，另两本永久作废。
2. **`grantManual` 自动装备更强的。** 玩家连「装备哪本」都不用想。
3. **只有一条效果轴。** 修士有 5 种职责（驻守／闭关／劳作／探索／宗门），
   功法跟其中 4 种毫无关系。
4. **纯 RNG，无法主动追求。** 想要某本只能反复刷洞天，没有积累感。
5. **重复掉落是纯浪费。** 已有功法再掉一次，什么都不会发生。
6. **功法阁面板是死的。** 真正的操作藏在仙途页中部一个小方块里。

**结论：秘籍需要的不是「更多功法」，而是「让功法之间有取舍」。**

---

## 二、设计目标

1. **产生真决策**：不能有「唯一最优解」，不同玩法该配不同功法。
2. **复用已有系统**：接到职责、洞天、攻伐、秘闻线索、灵石上，不另起炉灶。
3. **让重复掉落有用**：解决「掉到已有功法 = 白跑」。
4. **给玩家主动权**：能靠积累去追某本，而不是纯赌。
5. **顺带修掉一个既有失衡**（见 §四.3）。
6. **不改动已有存档语义**：`manuals` / `equippedManual` 保持原样，新字段全部可选。

## 三、机制设计

### 3.1 两条轴：道途 × 品阶

**道途**决定加成什么，**品阶**决定加多少。五条道途分别服务一种玩法，
正好对应现有的五种修士职责：

| 道途 | 效果轴 | 服务谁 | 接入点 |
|---|---|---|---|
| **炼气** | 闭关修为速度 | 长期养成 | `progressCultivators` 的修为增长 |
| **御守** | 修士战力 | 攻伐流 | `cultivateBasePower` 的求和 |
| **经营** | 劳作银两产出 | 凡人经济流 | `laborMult` → `silverPerSec` |
| **寻幽** | 秘闻发现 + 商路寻秘 | 秘闻流 | `explorePerSec` / `exploreTradeBonus` |
| **涉险** | 洞天生还率 + 灵石收益 | 赌命流 | `immortalAction('cave')` 的生还判定与奖励 |

**品阶**三档，数值递增：

| 品阶 | 基准强度 | 洞天出处 | 攻伐出处 |
|---|---|---|---|
| 黄阶 | 1× | 青苔小洞天 | 青木寨 |
| 玄阶 | 1.8× | 流霞洞天 / 玄阴秘境 | 黑水门 |
| 地阶 | 2.8× | 太虚古境 | 玄铁宗 |

**5 道途 × 3 品阶 = 15 本**，构成一张收藏网格。

### 3.2 两个位置：主修 + 辅修

- **主修**：效果 **100%**
- **辅修**：效果 **45%**
- **同一道途不可同时占两个位置**

这一条是「产生选择」的关键：15 本里你能带 2 本，且必须来自不同道途。
拿到地阶《周天星河诀》后，辅修位该放「御守」补战力还是「寻幽」补秘闻，
取决于你当前想推哪条线。

### 3.3 参悟：重复掉落的价值

每本功法有 **参悟度 0 ~ 5**，效果按 `×(1 + 0.12 × 参悟度)` 放大。

| 来源 | 效果 |
|---|---|
| 重复获得同一本 | 参悟度 +1 |
| 参悟度已满时重复获得 | 折算 **+2 灵石**（不浪费） |
| **主动参悟** | 花 **3 灵石 + 2 线索**，任选一本 +1 |

主动参悟是这条线唯一可以由玩家推动的部分，也是灵石与秘闻线索的新去处。
满参悟（5 层）相当于效果 **+60%**，一本满参悟的黄阶功法可以追上未参悟的玄阶。

### 3.4 宗门与家族功法分离（顺带修掉的失衡）

现状：`sect` 职责享有 **3.5× 修为速度**，而且完全安全；
`retreat`（闭关）只有 1×，却没有任何独占好处。**闭关目前严格劣于宗门。**

改法：**家族功法只对闭关修士生效，宗门修士不享受**（主题上也自洽——
宗门修的是宗门的法，家族的法传不到山门里）。

于是两条路各自成立：

| | 修为速度 | 安全 | 战力/经济贡献 | 天花板 |
|---|---|---|---|---|
| **宗门** | 3.5×（固定） | 完全安全 | 仅基础战力 | 与功法无关，恒定 |
| **闭关** | 1× × 功法倍率 | 留在族中，可随时改职责 | 可转驻守／劳作／探索 | 随功法收藏成长 |

功法收藏起来之后，闭关会反超宗门——这给了「把修士留在族里」一个明确理由。

### 3.5 获取途径

保留现有 RNG 掉落，但把 `grantManual` 从「按品阶取第 N 本」改成
「**按出处品阶，在该品阶的 5 本里加权随机**」。

于是：
- 洞天/攻伐决定**品阶**
- 道途随机
- 想要的特定道途靠**主动参悟**和反复历练去凑

不额外增加新的资源类型，不新增建筑。

## 四、数值表

### 4.1 十五本功法

效果值 `v` 的含义见各道途；参悟每层 ×1.12。

| 道途 | 黄阶 | 玄阶 | 地阶 |
|---|---|---|---|
| **炼气** | 吐纳真诀 `训练 +40%` | 沧澜引气法 `+110%` | 周天星河诀 `+220%` |
| **御守** | 铁骨桩功 `战力 +25%` | 玄甲护身诀 `+60%` | 不动明王经 `+130%` |
| **经营** | 节用篇 `劳作 +20%` | 货殖列传 `+50%` | 陶朱遗书 `+110%` |
| **寻幽** | 望气术 `秘闻 +30%` | 地脉堪舆图 `+75%` | 洞天指要 `+160%` |
| **涉险** | 健行散 `生还 +8pp / 灵石 +15%` | 龟息功 `+18pp / +35%` | 大衍遁法 `+35pp / +70%` |

> 前三本沿用原 `OBTAINABLE_MANUALS` 的 id（`breath` / `spring` / `star`）与数值，
> **保证旧存档里的 `manuals` / `equippedManual` 不需要迁移**。

### 4.2 关键常量

| 常量 | 值 | 说明 |
|---|---|---|
| `MANUAL_ATTUNE_MAX` | 5 | 参悟上限 |
| `MANUAL_ATTUNE_STEP` | 0.12 | 每层参悟的加成 |
| `MANUAL_ASSIST_RATIO` | 0.45 | 辅修位效果比例 |
| `MANUAL_ATTUNE_STONE_COST` | 3 | 主动参悟的灵石 |
| `MANUAL_ATTUNE_CLUE_COST` | 2 | 主动参悟的秘闻线索 |
| `MANUAL_DUPLICATE_STONES` | 2 | 满参悟后重复掉落的折算灵石 |

### 4.3 数值自检

- 满参悟地阶炼气：`1 + 2.20 × 1.6 = 4.52×` → 闭关反超宗门的 3.5×。
  未参悟的玄阶炼气：`2.10×` → 仍弱于宗门。**交叉点落在「参悟 2 层左右」**，
  即玩家需要认真投入才能让闭关路线成立。
- 主修地阶 + 辅修地阶（不同道途）是终局配置，但需要凑齐 2 本指定地阶。

## 五、界面设计

### 5.1 功法阁（`data-panel="cultivation-manuals"`）

从「一个空状态」改成完整面板，四段：

1. **装备栏**：主修 / 辅修两个格子
   - 有功法：显示名称、品阶、道途、参悟度、**当前实际加成**

3. **已收录列表**（15 行网格）：未获得的显示为暗色「未收录」，给出获取提示
   - 每行按钮：`设为主修` / `设为辅修` / `参悟`

4. **空状态**：一本都没有时保留原「道法未传，唯靠苦修」的文案

### 5.2 仙途页的家族功法块

保留一行摘要，把装备按钮换成「前往功法阁」的指引，避免两处重复操作。

### 8.2 实现时发现并顺手修掉的既有缺陷

1. **修了一个我自己引入的 bug**：洞天生还率公式原本在**三处**各写一遍（结算 / 面板预估 / 确认框）。
   我加「涉险 +生还」时只改了结算那处，**面板与确认框会向玩家谎报生还率**。
   已提取为 `caveSurvival(state, person, cave)`，三处共用 —— 顺带解决了原本的重复。
2. **宗门职业统计渲染成字面量 `undefined`**：`updateCultivatorRoster` 的计数器初始字典漏了 `sect`，
   而静态 HTML 里已经把这个 bug 固化下来了（`<strong>undefined</strong><span>宗门</span>`）。
   同时 `.cultivator-job-stats` 的 CSS 是 `repeat(4,…)` 但有 5 个职业，第 5 格会换行。两处都已修。
3. **`CULTIVATION_MANUALS` 与 `OBTAINABLE_MANUALS` 两张重复表**：前者供倍率查询、后者供掉落授予，
   只要有一个 id 对不上就会「装备 2.1× 却按 1.4× 结算」。已合并为一张，
   `OBTAINABLE_MANUALS` 保留为指向同一数组的别名（旧引用不用改）。
4. **`grantManual` 在重复获得时仍显示「获得《X》」**：现在返回结构化结果，
   由 `manualDropText` 分「新收录 / 参悟 +1 / 参悟满折灵石」三种文案。

### 8.3 验证

`scripts/smoke.mjs` —— 把单文件产物整段取出来，用最小 DOM 垫片真跑一遍，
再对秘籍做端到端断言。**100 项断言，全部通过**，随机源播种所以结果逐位可复现。
覆盖：目录结构、掉落与参悟、主动参悟、主修/辅修与同道途冲突、五项效果**各自接进了系统**
（不是只验函数）、宗门 vs 闭关的交叉点、洞天生还率、功法阁渲染、**五种损坏/旧版存档的迁移**，
以及一段基础玩法回归（建筑卡、科技、页面切换、纪事侧栏、职业统计）。

为跑通测试补了三处 DOM 垫片的真实缺口（真浏览器都有、垫片缺）：
`document.documentElement`、`Element.replaceChildren/append`、
以及**布尔属性到同名 property 的反射**（`<button disabled>` 读 `.disabled` 会一直是 false）。

### 8.4 已知的后续项

- **参悟不触发答题**。这是为了和炼气篇其它操作（灵池、寻龙尺、矿场、洞天、攻伐）保持一致——
  它们全都不出题。但这一篇因此完全没有复习强度，与「每次花钱都要背单词」的主前提脱节。
  **要让参悟出题的话，改 `[data-manual-action]` 的事件委托，走 `ui.askQuiz` 即可。**
- **攻伐零成本**（既有问题）：不花任何资源、无冷却，战败只有 65% 概率损失 1 人，
  修士够多时无限刷是纯期望正收益。秘籍的「御守」会进一步放大它。
- **灵石可再生来源仍只有矿场**（既有问题）：而开工矿场链要 6 灵石，
  前期只能靠坊市 10 万银两换 0.1 灵石。参悟每次要 3 灵石，会加剧这个瓶颈。
- 功法残卷、师承流派、与灵根的契合度。
