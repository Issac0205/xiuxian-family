## 八、推送失败的**真正根因**：历史分叉（我上一轮的诊断是错的）

**先认错**：我在 §六 · 1 里反复宣布的「链路层不可达 ⇒ 提交未推送」**只对了一半，且把根因判错了**。链路确实在若干时刻不通，但**推不上去的根本原因是本地与远端分叉**。

### 8.1 实测证据（`git merge-base` / 双向区间）

```
$ git merge-base 4569ca9 7876f3b
6d2ce7ff6f35583279db27a555238c0dc6358ebc        ← 共同祖先 = 科技线那轮
```

`7876f3b`（远端）与 `4569ca9`（本地）**父提交都是 `6d2ce7f`，是兄弟不是父子**；双向各有 1 个提交 = 教科书式分叉 ⇒ `git push` 报 `! [rejected] main -> main (non-fast-forward)`，**与网络无关**。

### 8.2 分叉是**我**造成的（`git log -1 --format=%P` 实测）

| 提交 | 父提交 | 说明 |
|---|---|---|
| `d6ae979` | `6d2ce7f` | 首版 docs/93 |
